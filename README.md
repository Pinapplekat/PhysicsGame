# MineBlox

A 2D sandbox game in vanilla JavaScript and canvas, built in May 2025.

**Features**
- Procedurally generated hilly terrain across grassland, desert, mountain, forest and snow biomes, with trees
- Player physics with gravity and collision
- Mine blocks into your inventory and place them back with right-click
- Collectible coins and gems
- Hotbar inventory (keys `1`–`9`)
- World saves automatically; export it and import it from a file; spawn objects at exact coordinates from the toolbar

**Controls:** `A`/`D` or arrows to move · `W`/`Space` to jump · `Shift` to sprint · left-click to mine · right-click to place · `R` to reset the world

## Run it
Open `index.html` in a browser.
